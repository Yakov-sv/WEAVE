# WEAVE — Go-to-Market стратегия

## Общая стратегия

**Beachhead → Expand → Scale → Ecosystem**

```
Фаза 0          Фаза 1           Фаза 2            Фаза 3           Фаза 4
Seed            Beachhead        Expand            Scale            Ecosystem
(мес 1-3)       (мес 4-9)        (мес 10-18)       (мес 19-30)      (мес 31+)
───────         ─────────        ────────          ────────         ────────
Waitlist        Developers       Creators          B2C + B2B        Plugin SDK

```

## Фаза 0 — Seed (месяцы 1–3)

**Цель:** Валидация гипотезы, сбор early adopters

### Действия

1. **Landing page + waitlist**
   - Домен: weave.app (или getweave.io)
   - Email capture + реферальная программа (early access за 3 реферала)
   - Прогресс-бар waitlist для социального доказательства

2. **Публичный концепт-документ**
   - Open RFC на GitHub (weave-roadmap repo)
   - Архитектурный документ публично
   - "Why we're building WEAVE" — серия статей

3. **Контент-стратегия**
   - Habr / Medium / Dev.to — технические статьи
   - X (Twitter) — devlog треды
   - Telegram-канал — раннее комьюнити
   - YouTube — короткие демо-видео

4. **Закрытая alpha**
   - 50–100 ранних пользователей из tech-сообществ
   - Еженедельные feedback-сессии
   - Итеративные улучшения

## Фаза 1 — Beachhead: Developers (месяцы 4–9)

**Цель:** Захватить нишу разработчиков как плацдарм

### Почему разработчики первыми

1. Самая "текучая" аудитория — готовы пробовать новое
2. Меньшая конкуренция в пересечении "Git + соцсеть + монетизация"
3. Разработчики — амбассадоры для других сегментов
4. Git — самое сложное технически; валидация через него = валидация всего

### MVP scope (фаза 1)

- Профиль + лента (как X)
- Каналы (как Telegram)
- Базовый Git (через Gitea)
- Платные подписки на каналы
- Импорт из GitHub

### Действия

1. **Product Hunt launch**
   - Подготовка: за 2 недели до launch
   - "Maker of the Day" цель
   - Связанные публикации на Habr/Dev.to/Medium

2. **OSS-программа**
   - Бесплатный Pro для open-source проектов
   - "Migrate from GitHub to WEAVE" кампания
   - Featured OSS-проекты на главной

3. **Hacker News / Reddit**
   - "Show HN: WEAVE — we replaced 5 dev tools with one"
   - AMA с founder
   - r/programming, r/webdev, r/opensource

4. **DevRel-партнёрства**
   - Партнёрство с tech-инфлюенсерами (спонсорство/early access)
   - Guest-публикации на tech-блогах
   - Подкасты (MSwDev, JS Jabber, etc.)

5. **Импорт-инструменты**
   - GitHub → WEAVE (двусторонняя синхронизация)
   - Telegram-канал → WEAVE-канал (импорт)
   - "Zero-migration" обещание

## Фаза 2 — Expand: Creators (месяцы 10–18)

**Цель:** Привлечь криэйторов/блогеров

### Новые функции (фаза 2)

- Stories / Reels (медиа-модуль)
- Алгоритмическая лента
- Витрина курсов/курсов/материалов
- Маркетплейс (продажа шаблонов, кода, пресетов)
- Кросс-платформенный импорт (Instagram/YouTube)

### Действия

1. **Creator-программа**
   - 0% комиссии первые 6 месяцев для мигрирующих авторов
   - "Move from Patreon to WEAVE" кампания
   - Featured creators на главной

2. **Инфлюенсер-партнёрства**
   - Оплата за миграцию (fixed + % от приведённых)
   - Tech-блогеры, dev-инфлюенсеры, онлайн-преподаватели
   - Кобрендингированный контент

3. **Маркетплейс-запуск**
   - Категории: код, шаблоны, курсы, пресеты, дизайн-ассеты
   - Кураторство на старте (featured listings)
   - Эскроу-платежи для доверия

4. **SEO-стратегия**
   - "Alternative to Patreon" лендинги
   - "Alternative to Gumroad" лендинги
   - "Sell code online" лендинги
   - Long-tail контент-маркетинг

## Фаза 3 — Scale: B2C + B2B (месяцы 19–30)

**Цель:** Массовое расширение + командные тарифы

### Новые функции (фаза 3)

- B2C: алгоритмическая лента, рекомендации, мобильное PWA
- B2B: командные пространства, SSO, ролевая модель, аудит-логи
- Открытый Plugin API
- Интеграции: Slack-import, Notion-import, Zoom/LiveKit

### Действия

1. **B2C-масштабирование**
   - Paid ads (Google, соцсети) — $20K/мес
   - Реферальная программа (даём Pro на 3 мес за реферал)
   - Вирусные механики (share-to-unlock, invite-only фичи)

2. **B2B-outbound**
   - Direct sales для команд 10–100 человек
   - SSO-интеграции (Google Workspace, Okta)
   - Кейсы: "Как команда X заменила Slack+GitHub+Patreon на WEAVE"
   - Конференции (Web Summit, TechCrunch Disrupt)

3. **Локализация**
   - EN, RU, ES, PT, ZH, JA, DE, FR
   - Локальные платёжные методы (для РФ, Бразилии, Индии)

4. **Plugin API**
   - Документация + SDK
   - Plugin marketplace (с комиссией 15%)
   - Hackathon для первых плагинов

**Цель:** Стать платформой/инфраструктурой

1. **Self-hosted WEAVE** (Enterprise)
   - On-premise версия
   - Лицензия BSL (source-available)
   - Enterprise support контракты

2. **Федерация**
   - ActivityPub поддержка (interop с Mastodon)
   - AT Protocol (interop с Bluesky)
   - Cross-instance messaging

3. **API Platform**
   - Полный REST/GraphQL API
   - Webhooks
   - Rate-limited public API (free tier + paid)

4. **White-label**
   - WEAVE-as-a-service для брендов

## Конкурентная тактика по фазам

### Против GitHub (фаза 1)
- "GitHub + Twitter + Telegram + Patreon в одном"
- Импорт из GitHub (не "замена", а "расширение")
- Двусторонняя синхронизация (push обратно в GitHub)

### Против Patreon (фаза 2)
- 0% комиссии первые 6 месяцев
- "Не нужна отдельная платформа для монетизации"
- Встроенная аудитория (Patreon не даёт ленту/чат)

### Против Telegram (фаза 1–2)
- Каналы + лента + Git + монетизация
- "Telegram не для кода, WEAVE — для всего"

### Против X (фаза 2–3)
- Лента + медиа + каналы + монетизация
- "X только для постов, WEAVE — для всего"

### Общий принцип: "Не заменяем — агрегируем"
- Сначала WEAVE работает рядом с другими платформами
- Импорт контента → постепенная миграция → network effect → нативное использование
