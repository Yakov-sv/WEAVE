# WEAVE — Обоснование названия

## Выбор

**WEAVE** (англ. *ткать, сплетать, переплетение*)

## Метафора

Как нити сплетаются в ткань на ткацком станке, так модули WEAVE сплетаются в единую платформу:
- Identity — основа (станок)
- Feed, Messaging, Git, Market, Payments — нити
- Результат — ткань цифрового присутствия пользователя

## Критерии выбора

| Критерий | Оценка |
|---|---|
| Международное произношение | ✅ Легко произносится на всех языках |
| Запоминаемость | ✅ 5 букв, одно слово |
| Домен | 🟡 weave.com занят; рассматривать weave.app, weave.so, getweave.io |
| Товарный знак | 🟡 Проверить в классах 9, 35, 38, 41, 42 |
| Ассоциации | ✅ "Сплетение, объединение, связь" |
| SEO | 🟡 Средняя конкуренция (есть другие "weave" бренды) |
| Брендинг | ✅ Сильный визуальный потенциал (переплетающиеся линии) |

## Конфликты (предварительный анализ)

**Рекомендация:** Проверить товарные знаки в юрисдикциях:
- США (USPTO) — классы 9, 35, 38, 41, 42
- ЕС (EUIPO)
- РФ (Роспатент)
- Великобритания (UKIPO)

При конфликте в классе 38 (коммуникации) — рассмотреть модификации:
- **WeaveHQ**

- **OpenWeave**
- **Weave.io**

## Визуальный потенциал

- Логотип: переплетающиеся нити/линии, образующие "W"
- Цветовая палитра: глубокий индиго + тёплый янтарь (контраст tech + creator)
- Анимация: нити сплетаются в логотип при загрузке
- Иконки модулей: каждая — отдельный узор сплетения
