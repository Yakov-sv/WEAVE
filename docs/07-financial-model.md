# WEAVE — Финансовая модель (3 года)

## Допущения

| Параметр | Значение | Обоснование |
|---|---|---|
| Средний доход на платящего (ARPPU) | $12 → $18/мес | Рост за счёт Team-тарифов |
| Конверсия Free → Paid | 1% → 2% → 3% | Industry standard для freemium |
| Конверсия Paid → Creator | 10% → 15% → 20% | Рост с маркетплейсом |
| Средний Team-размер | 5 человек | Малые/средние команды |
| Churn rate (monthly) | 8% → 5% → 4% | Улучшение retention |
| CAC (blended) | $15 → $12 → $10 | SEO + рефералы снижают CAC |
| Инфраструктура на пользователя | $0.50 → $0.30 → $0.20/мес | Экономия на масштабе |
