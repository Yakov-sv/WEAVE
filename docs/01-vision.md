# WEAVE — Видение и концепция

## Миссия

Создать единую платформу, где общение, творчество, код и монетизация сплетаются в одну ткань — без необходимости использовать 5 разных сервисов.

## Видение

WEAVE станет стандартной цифровой площадкой для разработчиков, криэйторов, команд и широкой аудитории — место, где один профиль заменяет Telegram, Instagram, X, GitHub и Patreon.

## Проблема

Современные пользователи фрагментированы по 5–7 платформам:

| Потребность | Платформа | Боль |
|---|---|---|
| Общение | Telegram, Discord | Отдельная экосистема |
| Короткие посты | X (Twitter) | Другая аудитория |
| Медиа / визуал | Instagram, TikTok | Третий профиль |
| Код | GitHub, GitLab | Четвёртый профиль |
| Монетизация | Patreon, Gumroad | Пятый сервис |
| Контент / курсы | Substack, Boosty | Шестой сервис |

**Следствие:** разрозненная аудитория, переключение контекста, дублирование усилий, потеря данных, зависимость от политик каждой платформы.

## Решение

**WEAVE** — модульная платформа (Federated Layers), где:

1. **Один профиль** = единая идентичность для всех модулей
2. **Шесть модулей** работают как грани единой платформы:
   - Identity — ядро профиля
   - Feed — лента (как X / Instagram)
   - Messaging — чаты и каналы (как Telegram)
   - Git — репозитории (как GitHub)
   - Market — маркетплейс (как Patreon / Gumroad)
   - Payments — платёжная инфраструктура
3. **Модули включаются по необходимости** — пользователь сам решает, какие грани активировать
4. **Монетизация встроена** — платные подписки, продажи, эскроу, чаевые

## Слоган

> **Where everything connects** — Где всё сплетается

## Ценности

1. **Единство** — один профиль, одна аудитория, один контекст
2. **Модульность** — включай только нужное
3. **Свобода монетизации** — авторы контролируют свои доходы
4. **Открытость** — Plugin SDK, импорт из других платформ, открытый API
5. **Принадлежность** — данные принадлежат пользователю (экспорт, self-hosted в будущем)

## Принципы дизайна

- **Progressive disclosure** — простой старт, глубокая функциональность по запросу
- **API-first** — каждый модуль имеет REST + WebSocket API
- **Event-driven** — модули общаются через события, не через прямые вызовы
- **Plugin-ready** — архитектура готова к сторонним модулям (MVP — встроенные, позже — SDK)

## Архитектурная метафора

Название **WEAVE** (ткать, сплетать) отражает суть: как нити ткани сплетаются в единое полотно, так модули сплетаются в единую платформу. Каждый модуль — нить, профиль — станок, а результат — ткань цифрового присутствия пользователя.

## Целевая аудитория (кратко)

| Сегмент | Профиль | Главное value |
|---|---|---|
| Разработчики | Indie, OSS-авторы, фрилансеры | Код + лента + канал + монетизация в одном |
| Криэйторы | Блогеры, преподаватели, авторы курсов | Медиа + лента + платный канал + продажи |
| B2C | Потребители контента | Всё в одном месте |
| B2B / Команды | Стартапы, студии, OSS-команды | Чат + Git + комьюнити + продажи |

Детально — в [Бизнес-плане](04-business-plan.md).

## Что НЕ делает WEAVE

- Не заменяет YouTube (длинное видео) — но интегрирует
- Не заменяет Spotify (стриминг музыки) — но позволяет продавать аудио
- Не заменяет Slack (enterprise chat) — но покрывает needs малых/средних команд
- Не является блокчейн/DeFi платформой — но поддерживает крипто-платежи опционально
