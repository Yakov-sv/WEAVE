## Детальный анализ конкурентов

### 1. Супер-аппы (общего назначения)

#### WeChat
- **Покрытие:** мессенджер + соцсеть + платежи + мини-аппы
- **Аудитория:** 1B+ MAU (Китай)
- **Чего нет:** Git, фокус на код/контент-монетизацию
- **Угроза:** Низкая (китайский рынок, другая модель)
- **Урок:** Супер-апп модель работает при достаточном network effect

#### Max (VK)
- **Покрытие:** мессенджер + каналы + платежи + мини-аппы
- **Аудитория:** РФ-ориентированная
- **Чего нет:** Git, медиа-лента, код, монетизация авторов
- **Угроза:** Средняя (могут добавить код-функции через мини-аппы)
- **Урок:** Российский рынок может быть ранним адоптером

#### X (бывший Twitter)
- **Покрытие:** лента + чат + планирует платежи
- **Аудитория:** 600M+ MAU
- **Чего нет:** Git, медиа-формат Instagram, маркетплейс
- **Угроза:** Средняя (Маск заявлял желание стать "everything app")
- **Урок:** "Everything app" — подтверждённая востребованная концепция

### 2. Git-платформы

#### GitHub
- **Покрытие:** Git + Discussions + Sponsors + Activity feed
- **Аудитория:** 100M+ пользователей
- **Чего нет:** Мессенджер, медиа-лента, маркетплейс
- **Угроза:** Высокая (могут добавить чат + монетизацию)
- **Урок:** GitHub Sponsors уже идёт в сторону монетизации, но медленно. Окно возможностей сужается.

#### GitLab
- **Покрытие:** Git + CI/CD + Enterprise
- **Аудитория:** 30M+ (enterprise-фокус)
- **Чего нет:** Соцсеть, мессенджер, монетизация
- **Угроза:** Низкая (enterprise-фокус, не пойдут в B2C/криэйторов)

#### Gitea / Forgejo
- **Покрытие:** Self-hosted Git, лёгкий
- **Угроза:** Низкая (не платформа, а инструмент)
- **Возможность:** WEAVE использует Gitea как backend

### 3. Контент-монетизация

#### Patreon
- **Покрытие:** платные подписки на авторов
- **Аудитория:** 8M+ патронов, 250K+ авторов
- **Чего нет:** Мессенджер, лента, Git, медиа-формат
- **Комиссия:** 8–12%
- **Угроза:** Низкая (не расширятся в Git/мессенджер)
- **Урок:** Модель платных подписок подтверждена

#### Substack
- **Покрытие:** платные рассылки + блог
- **Чего нет:** Чат в реальном времени, медиа, Git, маркетплейс
- **Комиссия:** 10%
- **Угроза:** Низкая

#### Boosty
- **Покрытие:** платные подписки + контент (РФ/CIS)
- **Чего нет:** Git, мессенджер, лента как соцсеть
- **Комиссия:** ~10%
- **Угроза:** Низкая (региональная)

#### Gumroad
- **Покрытие:** маркетплейс цифровых товаров
- **Чего нет:** Соцсеть, мессенджер, Git
- **Комиссия:** 10%
- **Угроза:** Низкая

### 4. Мессенджеры + комьюнити

#### Telegram
- **Покрытие:** мессенджер + каналы + платные подписки + Mini Apps
- **Аудитория:** 900M+ MAU
- **Чего нет:** Git, медиа-лента как Instagram, код, маркетплейс
- **Угроза:** Высокая (могут добавить через Mini Apps, но полноценный Git маловероятен)
- **Урок:** Telegram-каналы + платные подписки — подтверждённая модель

#### Discord
- **Покрытие:** чат + сообщества + Nitro подписки
- **Аудитория:** 200M+ MAU
- **Чего нет:** Лента как X/Instagram, Git, маркетплейс
- **Угроза:** Средняя (могут добавить ленту/медиа)

### 5. Децентрализованные соцсети

#### Mastodon
- **Покрытие:** децентрализованная лента (ActivityPub)
- **Чего нет:** Мессенджер, Git, монетизация, медиа
- **Угроза:** Низкая
- **Возможность:** WEAVE может поддержать ActivityPub в будущем

#### Nostr
- **Покрытие:** децентрализованный протокол
- **Угроза:** Низкая
- **Возможность:** Интеграция протокола для нишевой аудитории

#### Bluesky
- **Покрытие:** децентрализованная лента (AT Protocol)
- **Угроза:** Низкая
- **Возможность:** AT Protocol интеграция

## SWOT-анализ WEAVE

### Strengths (Сильные стороны)
- Уникальное пересечение: единственная платформа с Git + соцсеть + мессенджер + монетизация
- Модульная архитектура — гибкость для разных сегментов
- Импорт из GitHub/Telegram — низкий барьер миграции
- Монетизация встроена с первого дня
- Открытый Plugin API (будущее) — экосистемный потенциал

### Weaknesses (Слабые стороны)
- Новый бренд — нет узнаваемости
- Нет network effect на старте (пустая платформа)
- Сложность продукта (4+ функции = риск UX-перегруза)
- Команда маленькая на старте
- Нет нативного мобильного приложения (PWA на старте)

### Opportunities (Возможности)
- Растущее недовольство авторов комиссиями Patreon/Substack
- Усиление децентрализации (тренд на sovereignty)
- Рост creator-экономики ($100B+ к 2030)
- Ниша "разработчик-криэйтор" растёт (dev-блогеры, tech-инфлюенсеры)
- Новые платёжные технологии (крипто, passkeys)
- Российский/азиатский рынок раньше готов к супер-аппам

### Threats (Угрозы)
- GitHub может добавить мессенджер/монетизацию
- Telegram может добавить Git-функции через Mini Apps
- Discord может добавить ленту/медиа
- Регуляторы (GDPR, DMCA, financial compliance)
- Стоимость инфраструктуры (Git + медиа + realtime)
- Big Tech может скопировать концепт

## TAM / SAM / SOM

| Уровень | Рынок | Размер |
|---|---|---|
| **TAM** (Total Addressable Market) | Global creator economy + dev tools + messaging | $150B+ |
| **SAM** (Serviceable Addressable Market) | Developer-creators + tech-content creators + teams | $15B |
| **SOM** (Serviceable Obtainable Market, год 3) | 0.5% от SAM | $75M |

### Драйверы роста TAM
- Creator economy: $100B к 2030 (Goldman Sachs)
- Developer tools market: $50B+ (растёт 15% YoY)
- Messaging platforms: 3B+ пользователей глобально
- Subscription economy: $1.5T к 2025 (UBS)

## Вывод

На рынке **нет прямого конкурента**, объединяющего все 5 функций. WEAVE занимает уникальную позицию. Главное окно возможностей — 12–18 месяцев, пока GitHub/Telegram/Discord не начали двигаться в этом направлении. Стратегия — beachhead через разработчиков, затем расширение на криэйторов.
