## Стратегия ценообразования

### Принципы

1. **Free-тир щедрый** — network effect важнее краткосрочной монетизации
2. **Creator-тир конкурирует с Patreon** — сопоставимая цена + больше возможностей
3. **0% комиссии первые $1000/мес** — стимул для миграции авторов
4. **Team-тир заменяет Slack+GitHub** — $25 vs $4+$8=$12 (но больше функций)
5. **OSS бесплатно** — стратегическая инвестиция в комьюнити

## Выплаты авторам

### Модель выплат

```
Подписчик платит $10/мес
    ↓
Stripe обрабатывает платёж ($0.30 + 2.9% = $0.59)
    ↓
WEAVE комиссия 10% = $1.00
    ↓
Автор получает $10 - $0.59 - $1.00 = $8.41
    ↓
Накапливается в балансе автора
    ↓
Выплата: автоматически при достижении $50 или ежемесячно
    ↓
Stripe Connect payout → банк автора
```

### Payout-условия

| Условие | Значение |
|---|---|
| Минимальная сумма выплаты | $50 |
| Частота выплат | Ежемесячно (или по достижению минимума) |
| Метод выплаты | Stripe Connect (bank transfer) |
| Hold-период | 7 дней (anti-fraud) |
| Tax reporting | 1099-K для США (с года 2) |
