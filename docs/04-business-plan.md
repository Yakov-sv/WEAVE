# WEAVE — Бизнес-план

## Executive Summary

**WEAVE** — модульная платформа (Federated Layers), объединяющая мессенджер, соцсеть, медиа, Git-хостинг и маркетплейс монетизации в одном профиле. Один пользователь — одна идентичность — шесть модулей.

**Бизнес-модель:** Freemium + комиссии с транзакций (подписки 10%, маркетплейс 10%, чаевые 5%) + B2B-тарифы.

**Цель:** 1.5M регистраций и $10M дохода к концу года 3.

**Финансирование:** Bootstrapped → Seed ($1.5M) на месяце 6–9 → Series A ($8M) на месяце 18–24.

---

## 1. Проблема

Современный цифровой пользователь (особенно разработчик-криэйтор) фрагментирован по 5–7 платформам. Каждый сервис — отдельный профиль, отдельная аудитория, отдельный контекст, отдельная монетизация.

**Количественная боль:**
- Средний разработчик использует GitHub + Twitter + Telegram + Discord + Patreon = 5 сервисов
- Переключение контекста стоит ~23 минуты фокуса (UC Irvine study)
- Автор теряет 30–40% аудитории из-за фрагментации (followers ≠ subscribers ≠ patrons)

## 2. Решение

WEAVE объединяет 6 модулей в одном профиле:

| Модуль | Функция | Аналог |
|---|---|---|
| Identity | Профиль, SSO, репутация | — |
| Feed | Лента постов, медиа, stories | X + Instagram |
| Messaging | Чаты, каналы, платные подписки | Telegram |
| Git | Репозитории, PR, issues | GitHub |
| Market | Маркетплейс кода/курсов/шаблонов | Patreon + Gumroad |
| Payments | Подписки, покупки, эскроу | Stripe |

**Ключевое отличие:** не агрегатор (как Franz/Shift), а нативная платформа — все функции работают в едином UI с единой идентичностью.

## 3. Целевая аудитория

### Сегмент A — Разработчики / технари

**Профиль:** indie-разработчики, OSS-авторы, тех-блогеры, фрилансеры
**Размер:** ~30M глобально
**Боль:** GitHub (код) + Twitter (анонсы) + Telegram (комьюнити) + Patreon (монетизация) + Discord (чат) = 5 платформ
**Value WEAVE:** Один профиль = репо + лента + канал + чат + продажи кода
**Готовность платить:** $8–25/мес
**Роль в стратегии:** Beachhead сегмент (первые пользователи, амбассадоры)

### Сегмент B — Криэйторы / блогеры

**Профиль:** YouTube/Instagram/TikTok блогеры, онлайн-преподаватели, авторы курсов
**Размер:** ~50M глобально (207M+ создателей контента, growing)
**Боль:** Instagram (визуал) + X (мысли) + Telegram (близость) + Patreon (деньги) + GitHub (инструменты курса)
**Value WEAVE:** Лента + медиа + канал + платная подписка + репозиторий материалов
**Готовность платить:** $15–50/мес + комиссии
**Роль в стратегии:** Расширение (фаза 2), основной драйвер монетизации

### Сегмент C — Широкая аудитория (B2C)

**Профиль:** потребители контента, подписчики, покупатели
**Размер:** 3B+ (пользователи соцсетей/мессенджеров)
**Боль:** подписки разбросаны, контент в 5 местах
**Value WEAVE:** Один профиль для всего
**Готовность платить:** $0–8/мес (freemium)
**Роль в стратегии:** Масштаб (фаза 3), network effect

### Сегмент D — Команды / B2B

**Профиль:** стартапы, студии, OSS-команды, онлайн-школы
**Размер:** ~10M команд глобально
**Боль:** Slack (чат) + GitHub (код) + Notion (контент) + Patreon (монетизация) + нет единого комьюнити
**Value WEAVE:** Командное пространство = чат + Git + канал + маркетплейс + медиа
**Готовность платить:** $25/мес/участник
**Роль в стратегии:** B2B-доход (фаза 3), стабильный MRR

## 4. Value Proposition

### Для разработчиков
> "Веди репозиторий, анонсируй релизы в ленте, общайся с комьюнити в канале и продавай премиум-код — в одном профиле. Без 5 вкладок."

### Для криэйторов
> "Публикуй медиа, веди ленту, общайся с фанатами в платном канале, продавай курсы и материалы — в одном месте. Аудитория не фрагментирована."

### Для команд
> "Чат команды + Git-репозитории + публичный канал для комьюнити + маркетплейс для продаж — одно пространство вместо 4 сервисов."

## 6. Конкурентное преимущество

| Преимущество | Обоснование |
|---|---|
| Единственное место "4-в-1" | Никто не объединяет Git + соцсеть + мессенджер + монетизация |
| Импорт из других платформ | Низкий барьер миграции (GitHub, Telegram) |
| Монетизация с первого дня | Авторы могут зарабатывать сразу |
| Модульность | Включай только нужные функции |
| Plugin API (будущее) | Экосистемный потенциал |
| OSS-программа | Бесплатный Premium для open-source |
